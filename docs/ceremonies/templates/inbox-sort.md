## Purpose

The Inbox Sort meeting is a weekly triage session to review, categorize, and prioritize incoming requests, bug reports, support tickets, and new ideas. This ensures nothing falls through the cracks and high-priority items are addressed promptly.

**Key Outcomes:**
- Review all new incoming items since last sort
- Categorize and label items appropriately
- Prioritize urgent issues
- Route items to appropriate backlog or owner
- Identify items requiring immediate attention

## Categorization Guide

### Priority Levels
| Priority | Definition | Response Time |
|----------|------------|---------------|
| P0 - Critical | System down, data loss, security issue | Immediate |
| P1 - High | Major feature broken, blocking users | Within 24 hours |
| P2 - Medium | Feature degraded, workaround exists | Within sprint |
| P3 - Low | Minor issue, enhancement | Backlog |

### Categories
| Category | Description |
|----------|-------------|
| Bug | Something is broken |
| Feature | New functionality request |
| Enhancement | Improvement to existing feature |
| Tech Debt | Internal technical improvement |
| Support | Question or help request |
| Documentation | Docs update needed |
