## Purpose

Sprint Planning establishes the work to be performed during the sprint. This collaborative effort defines the Sprint Goal and selects Product Backlog items that can be delivered within the sprint timebox.

**Key Outcomes:**
- Define a clear, achievable Sprint Goal
- Select and commit to Product Backlog items
- Create an initial plan for delivering the selected items
- Team commitment to the sprint scope
